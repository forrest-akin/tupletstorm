# Handoff: CI reads its toolchains from mise.toml

`mise.toml` (added by `build: pin rust and node with mise`) is the single version pin for Rust,
its targets/components, and Node. CI must install from it, with no versions of its own.

## Change (one commit)

In `.github/workflows/ci.yml`, replace `dtolnay/rust-toolchain@stable` and
`actions/setup-node@v4` with `jdx/mise-action` (current major; read its README raw with
`curl -sL` or `trafilatura -u`, not WebFetch). Remove every hard-coded toolchain version or
`node-version` from the workflow. Keep `Swatinem/rust-cache`. Keep npm dependency caching if the
old setup-node step had it (e.g. `actions/cache` on `~/.npm` keyed by `web/package-lock.json`).
Change no job's commands.

If any job needs a toolchain `mise.toml` doesn't provide (e.g. the wasm target), add it to
`mise.toml`, not to the workflow.

Update any README/CLAUDE.md line describing how CI installs toolchains.
