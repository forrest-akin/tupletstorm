# RFDs

Design decisions are written down as RFDs (Requests for Discussion) before or
while they are built, in the style of Oxide's process
([RFD 1](https://rfd.shared.oxide.computer/rfd/0001)).

Each RFD is a Markdown file named `NNNN-short-title.md`, starting with:

```
state: prediscussion | ideation | discussion | published | committed | abandoned
authors: Name <email>
discussion: link to the pull request or issue
```

- **prediscussion**: being drafted.
- **ideation**: a placeholder for an idea, not yet a proposal.
- **discussion**: open for comment, usually as a pull request.
- **published**: agreed; may still be amended.
- **committed**: implemented, and the document matches what was built.
- **abandoned**: not pursued; kept for the record.
